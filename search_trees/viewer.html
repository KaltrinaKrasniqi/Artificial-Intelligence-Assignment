How to read the tree

  1. Each node is one state; each edge labels the action taken from its parent.
  2. IDs follow breadth-first generation in the displayed tree. A repeated state points to the earlier discovery ID and is not expanded again.
  3. Invalid attempted actions are shown for explanation; a legal search would discard them.
  4. A depth cutoff means the rest of that subtree is omitted from this picture. It is not proof of failure.

Node colors identify status, not a heuristic score. The graph of all states can contain cycles; this is a discovery tree with repeat leaves, not a claim that the underlying state graph is a tree.
